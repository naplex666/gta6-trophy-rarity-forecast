Earners-over-players forecaster for GTA VI trophy rarities on Exophase: it models each trophy's earners and the tracked player count apart, each with a saturating curve, and forecasts their ratio a week out — so an early explosion in tracked players cannot masquerade as trophies getting rarer. Quantiles are honest about Exophase refresh shocks, which can drop every rate at once.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
